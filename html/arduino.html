Aulas de Arduíno

O Arduino é uma plataforma de prototipagem eletrônica open-source baseada em hardware e software livres. Seu microcontrolador lê entradas através de pinos digitais e analógicos (conectados a sensores) e executa saídas (acionando motores, relés ou displays) com base em um código programado em C/C++.

Práticas realizadas em sala

Realizamos estas atividades em grupo para conhecer a leitura de sensores com Arduíno.

1. Sensor ultrassônico

Em sala, nosso grupo trabalhou com um sensor ultrassônico para medir distâncias. O vídeo registra a prática e mostra como a leitura do sensor pode ser usada em um projeto de automação.

Exemplo de código

const int trig = 9;
const int echo = 10;

void setup() {
  Serial.begin(9600);
  pinMode(trig, OUTPUT);
  pinMode(echo, INPUT);
}

void loop() {
  digitalWrite(trig, LOW);
  delayMicroseconds(2);
  digitalWrite(trig, HIGH);
  delayMicroseconds(10);
  digitalWrite(trig, LOW);

  unsigned long tempo = pulseIn(echo, HIGH, 30000);
  if (tempo > 0) Serial.println(tempo * 0.0343 / 2); // Distância em cm
  delay(500);
}

2. Sensor de presença

Também realizamos em grupo uma atividade com sensor de presença para observar a detecção de movimento. O vídeo apresenta a experiência feita em sala; o código abaixo mostra um exemplo simples de acionamento de LED com a leitura do sensor.

Exemplo de código

const int pir = 2;
const int led = 13;

void setup() {
  pinMode(pir, INPUT);
  pinMode(led, OUTPUT);
}

void loop() {
  int movimento = digitalRead(pir);
  digitalWrite(led, movimento);
  delay(100);
}
